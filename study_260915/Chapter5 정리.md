# Chapter 5 복습 노트: 프롬프트 만들기와 예시 선택

## 한눈에 보는 흐름

`질문 양식 만들기 → 값 채우기 → 모델에 전달 → 필요하면 좋은 예시를 골라 함께 전달 → 답변 받기`

프롬프트는 AI에게 보내는 **질문 설계도**입니다. 빈칸과 예시를 잘 준비하면 같은 모델도 더 일관된 답변을 만들기 쉬워집니다.

| 챕터 | 핵심 | 기억할 한 가지 |
|---|---|---|
| 5-1 | `PromptTemplate` | `{country}`처럼 바뀌는 부분을 빈칸으로 둔다. |
| 5-2 | `partial`과 함수 | 매번 넣지 않을 값(오늘 날짜 등)은 미리 연결할 수 있다. |
| 5-3 | YAML 프롬프트 | 질문 양식을 코드 밖 YAML 파일로 분리해 관리한다. |
| 5-4 | `ChatPromptTemplate` | system·human·ai 역할로 대화의 맥락을 만든다. |
| 5-5 | `MessagesPlaceholder` | 이전 대화를 통째로 넣어 요약 같은 작업을 한다. |
| 5-6 | 고정 Few-shot | 질문·답변 예시를 항상 함께 보여 준다. |
| 5-7 | 의미 기반 예시 선택 | 새 질문과 비슷한 예시만 자동으로 고른다. |
| 5-8 | 대화형 Few-shot | 선택된 예시를 human/ai 대화 형식으로 넣는다. |
| 5-9 | 사용자 정의 선택기 | 예시 선택 기준을 직접 만든 선택기를 사용한다. |

## 1. 템플릿: 바뀌는 질문을 안전하게 만들기

```python
prompt = PromptTemplate.from_template("{country}의 수도는 어디인가요?")
prompt.format(country="대한민국")
```

- `{country}`는 나중에 실제 값으로 바뀌는 자리입니다.
- `format()`은 질문 문장만 완성합니다. 아직 AI 호출이나 비용은 발생하지 않습니다.
- `prompt | llm`으로 연결하고 `invoke()`하면 완성된 질문이 모델로 전달됩니다.

`partial`은 자주 바뀌지 않는 값을 미리 채우는 기능입니다. 오늘 날짜처럼 실행할 때 계산해야 하는 값은 함수를 연결할 수도 있습니다.

## 2. 대화 프롬프트: AI에게 역할과 맥락 주기

```python
ChatPromptTemplate.from_messages([
    ("system", "당신은 친절한 도우미입니다."),
    ("human", "{question}"),
])
```

- `system`: AI의 역할·말투·규칙
- `human`: 사용자의 요청
- `ai`: 답변 예시 또는 이전 답변

`MessagesPlaceholder("conversation")`은 이전 대화 목록을 넣는 자리입니다. 긴 대화를 요약하거나, 앞 대화 내용을 기억하게 하는 데 씁니다.

## 3. YAML: 질문 양식과 코드를 분리하기

`load_prompt("파일명.yaml")`으로 YAML에 저장한 프롬프트를 불러올 수 있습니다. 질문 문구를 바꾸기 위해 파이썬 코드를 건드리지 않아도 되어, 양식 관리가 편해집니다.

## 4. Few-shot: 답변 예시를 먼저 보여 주기

Few-shot은 모델에게 **입력과 원하는 답변의 예시**를 먼저 보여 준 뒤 새 질문을 주는 방법입니다.

```text
예시 질문 → 예시 답변
새 질문 → 모델 답변
```

- `FewShotPromptTemplate`: 일반 텍스트 질문·답변 형식에 사용
- `FewShotChatMessagePromptTemplate`: human/ai 대화 메시지 형식에 사용
- 형식, 말투, 풀이 순서를 맞추고 싶을 때 유용합니다.

## 5. 모든 예시 대신 알맞은 예시 고르기

예시가 많으면 전부 넣는 대신, 새 질문과 가까운 예시만 고르는 편이 효율적입니다.

- **임베딩**: 문장의 뜻을 숫자 묶음으로 바꾼 것
- **Chroma**: 이 숫자 묶음을 저장하고 비슷한 내용을 찾는 저장소
- **SemanticSimilarityExampleSelector**: 뜻이 가장 비슷한 예시를 선택
- `k=1`: 가장 가까운 예시 한 개만 선택

흐름은 `새 질문 → 의미 비교 → 관련 예시 선택 → 프롬프트에 삽입 → 모델 호출`입니다.

## 6. 체인과 출력

```python
chain = prompt | llm | StrOutputParser()
```

- `|`는 앞 단계의 결과를 다음 단계에 넘기는 연결입니다.
- `StrOutputParser()`는 모델 응답 객체에서 텍스트만 꺼내기 쉽게 합니다.
- `invoke()`는 답변 전체를 받은 뒤 반환하고, `stream()`은 생성되는 조각부터 보여 줍니다.
