# LangChain Prompt 정리

## 1. LangSmith 프로젝트 설정

```python
from dotenv import load_dotenv
from langchain_teddynote import logging

load_dotenv()

logging.langsmith("0915-Prompt")
```

### 역할

- `load_dotenv()`
  - `.env` 파일에 저장된 API Key를 불러온다.

- `logging.langsmith("0915-Prompt")`
  - LangChain 실행 기록을 LangSmith에 저장하도록 설정한다.
  - `"0915-Prompt"`는 파일명이 아니라 LangSmith의 프로젝트 이름이다.

예를 들어 아래처럼 작성해도 실행에는 문제가 없다.

```python
logging.langsmith("Chapter_5_1.ipynb")
```

하지만 실제 `.ipynb` 파일을 연결하는 것은 아니다.

따라서 보통은 아래처럼 프로젝트 이름만 작성해도 된다.

```python
logging.langsmith("Chapter_5_1")
```


## 2. PromptTemplate이란?

먼저 일반 문자열로 프롬프트의 틀을 만든다.

```python
template = """
{country}의 수도는 어디인가요?
"""
```

여기서 `{country}`는 나중에 실제 값을 넣을 자리다.

이 문자열을 LangChain에서 사용할 수 있는 프롬프트 객체로 바꾼다.

```python
from langchain_core.prompts import PromptTemplate

prompt = PromptTemplate.from_template(template)
```

### 핵심

```python
PromptTemplate.from_template(template)
```

일반 문자열을 LangChain용 `PromptTemplate` 객체로 변환한다.

쉽게 보면:

```text
template
→ 일반 문자열

prompt
→ LangChain에서 사용할 수 있는 프롬프트 객체
```


## 3. 프롬프트에 실제 값 넣기

```python
prompt = prompt.format(country="대한민국")
```

`{country}` 자리에 `"대한민국"`을 넣는다.

변경 전:

```text
{country}의 수도는 어디인가요?
```

변경 후:

```text
대한민국의 수도는 어디인가요?
```

즉 `.format()`은 프롬프트의 변수 자리에 실제 값을 넣어 완성된 문장을 만드는 기능이다.

주의할 점은 `.format()`을 실행하면 완성된 문자열이 만들어진다는 것이다.

헷갈리지 않게 아래처럼 변수명을 나누어도 된다.

```python
prompt_template = PromptTemplate.from_template(template)

formatted_prompt = prompt_template.format(
    country="대한민국"
)
```


## 4. 마지막에 `prompt`를 또 쓰는 이유

```python
prompt = prompt.format(country="대한민국")
prompt
```

마지막의 `prompt`는 새로운 기능이 아니다.

Jupyter Notebook에서는 셀의 마지막 줄에 변수명을 적으면 그 변수의 값을 화면에 보여준다.

아래 코드와 비슷한 역할이다.

```python
print(prompt)
```

즉 마지막의 `prompt`는 결과 확인용이다.

없어도 코드 실행에는 문제가 없다.


## 5. 전체 흐름

```python
from langchain_core.prompts import PromptTemplate

# 1. 프롬프트 문장 틀 작성
template = """
{country}의 수도는 어디인가요?
"""

# 2. LangChain용 PromptTemplate으로 변환
prompt = PromptTemplate.from_template(template)

# 3. 변수에 실제 값 넣기
result = prompt.format(country="대한민국")

# 4. 결과 확인
result
```

결과:

```text
대한민국의 수도는 어디인가요?
```


## 6. Runnable 실행 방식

LangChain의 여러 객체는 Runnable 방식으로 실행할 수 있다.

### invoke()

입력 하나를 넣고 결과 하나를 받는다.

```python
result = chain.invoke("질문")
```

### stream()

결과를 한 번에 받지 않고 조금씩 받는다.

```python
for chunk in chain.stream("질문"):
    print(chunk)
```

### batch()

여러 입력을 한 번에 처리한다.

```python
results = chain.batch([
    "질문1",
    "질문2",
    "질문3"
])
```

쉽게 기억하면:

```text
invoke = 하나 실행
stream = 결과를 조금씩 받기
batch = 여러 개 실행
```


## 핵심 요약

```text
template
= 프롬프트의 기본 문장

PromptTemplate.from_template()
= 일반 문자열을 LangChain 프롬프트 객체로 변환

.format()
= {변수} 자리에 실제 값을 넣음

prompt
= 사용자가 정한 변수명

Notebook 마지막 줄의 prompt
= 현재 값 확인용

logging.langsmith()
= LangSmith에서 실행 기록을 모을 프로젝트 이름 설정

invoke()
= 하나 실행

stream()
= 결과를 조금씩 받음

batch()
= 여러 입력을 한 번에 실행
```

# Chapter 5-6: 고정 예시를 이용한 Few-shot Prompt

## 2. Few-shot Prompt란?

Few-shot Prompt는 모델에게 몇 개의 질문·답변 예시를 먼저 보여 주는 방법이다.

모델은 예시를 참고해 다음 내용을 파악한다.

- 어떤 방식으로 문제를 풀어야 하는지
- 어떤 형태로 답변해야 하는지
- 답변을 얼마나 자세히 작성해야 하는지

예시는 다음과 같이 질문과 답변을 한 쌍으로 구성한다.

```python
examples = [
    {
        "question": "질문 예시",
        "answer": "답변 예시",
    }
]
```

---

## 3. 예시 출력 형식 만들기

`PromptTemplate`은 질문과 답변을 어떤 모양으로 배치할지 정하는 틀이다.

```python
from langchain_core.prompts import PromptTemplate

example_prompt = PromptTemplate.from_template(
    "Question:\n{question}\nAnswer:\n{answer}"
)
```

여기서 `{question}`과 `{answer}`는 나중에 실제 값으로 교체되는 자리표시자다.

```python
example_prompt.format(**examples[0])
```

`**examples[0]`은 딕셔너리의 `question`과 `answer`를 같은 이름의 자리표시자에 각각 넣는다는 뜻이다.

---

## 4. Few-shot Prompt 완성하기

`FewShotPromptTemplate`은 예시와 새로운 질문을 하나의 프롬프트로 합친다.

```python
from langchain_core.prompts.few_shot import FewShotPromptTemplate

prompt = FewShotPromptTemplate(
    examples=examples,
    example_prompt=example_prompt,
    suffix="Question:\n{question}\nAnswer:",
    input_variables=["question"],
)
```

각 항목의 의미는 다음과 같다.

- `examples`: 모델에게 보여 줄 고정 예시
- `example_prompt`: 각 예시의 출력 형식
- `suffix`: 예시 뒤에 붙일 새로운 질문 형식
- `input_variables`: 외부에서 입력받을 변수 이름

최종 프롬프트는 다음과 같이 만든다.

```python
question = "새로운 질문"
final_prompt = prompt.format(question=question)

print(final_prompt)
```

작동 흐름은 다음과 같다.

```text
예시 데이터
    ↓
예시 출력 형식 적용
    ↓
새로운 질문 추가
    ↓
최종 프롬프트 완성
```

---

## 5. ChatOpenAI로 답변 생성하기

```python
from langchain_openai import ChatOpenAI
from langchain_teddynote.messages import stream_response

llm = ChatOpenAI()

answer = llm.stream(final_prompt)
stream_response(answer)
```

- `ChatOpenAI()`는 답변을 생성하는 모델 객체다.
- `stream()`은 답변을 작은 조각으로 나누어 전달한다.
- `stream_response()`는 전달받은 답변 조각을 화면에 이어서 출력한다.

스트리밍을 사용하면 전체 답변이 완성될 때까지 기다리지 않고 생성되는 내용을 바로 볼 수 있다.

---

## 6. LCEL 체인으로 연결하기

LCEL은 LangChain의 여러 작업을 하나의 실행 흐름으로 연결하는 문법이다.

```python
from langchain_core.output_parsers import StrOutputParser

chain = prompt | llm | StrOutputParser()
```

`|` 연산자는 앞 단계의 결과를 다음 단계의 입력으로 전달한다.

```text
Few-shot Prompt
    ↓
ChatOpenAI
    ↓
문자열 답변
```

각 단계의 역할은 다음과 같다.

- `prompt`: 입력값으로 최종 프롬프트 생성
- `llm`: 프롬프트를 읽고 답변 생성
- `StrOutputParser()`: 모델 응답 객체에서 실제 답변 문자열 추출

체인은 다음과 같이 실행한다.

```python
answer = chain.stream(
    {"question": "새로운 질문"}
)

stream_response(answer)
```

# Chapter 5-7: 의미가 비슷한 예시를 자동 선택하는 Prompt

## 7. 고정 예시 방식의 한계

Chapter 5-6에서는 모든 예시를 항상 프롬프트에 넣었다.

예시가 많아지면 다음 문제가 생길 수 있다.

- 프롬프트가 불필요하게 길어진다.
- 질문과 관계없는 예시도 포함된다.
- 모델 사용 비용과 처리 시간이 증가한다.

이를 해결하기 위해 Chapter 5-7에서는 새 질문과 의미가 가장 비슷한 예시만 자동으로 선택한다.

---

## 8. Embedding이란?

Embedding은 문장의 의미를 컴퓨터가 비교할 수 있도록 숫자 목록인 벡터로 변환하는 기술이다.

예를 들어 다음 두 문장은 표현은 다르지만 의미가 비슷하다.

```text
자동차 가격이 얼마인가요?
이 차량은 얼마에 판매되나요?
```

Embedding을 사용하면 단어가 정확히 같지 않아도 문장의 의미가 비슷한지 비교할 수 있다.

```python
from langchain_openai import OpenAIEmbeddings

embeddings = OpenAIEmbeddings()
```

---

## 9. Chroma란?

Chroma는 Embedding으로 변환한 데이터를 저장하고 검색하는 벡터 저장소다.

```python
from langchain_chroma import Chroma

chroma = Chroma(
    "examples_selector",
    OpenAIEmbeddings(),
)
```

일반적인 데이터베이스가 정확히 일치하는 값을 찾는다면, 벡터 저장소는 의미가 비슷한 내용을 찾는 데 사용한다.

패키지가 없다면 프로젝트 폴더의 CMD에서 다음 명령어로 설치한다.

```cmd
.\.venv\Scripts\python.exe -m pip install langchain-chroma
```

설치 후에는 노트북 커널을 재시작해야 한다.

## 10. 예시 데이터 준비하기

예제 선택기가 비교할 질문·답변 목록을 먼저 선언해야 한다.

```python
examples = [
    {
        "question": "스티브 잡스와 빌 게이츠 중 누가 더 오래 살았나요?",
        "answer": "스티브 잡스는 56세에 사망했고, 빌 게이츠는 그보다 오래 살았습니다.",
    },
    {
        "question": "에펠탑과 롯데월드타워 중 어느 것이 더 높은가요?",
        "answer": "롯데월드타워가 에펠탑보다 더 높습니다.",
    },
]
```

다른 노트북에서 만든 변수는 현재 노트북으로 자동 전달되지 않는다. 따라서 `examples`는 사용하는 노트북 안에서 직접 선언해야 한다.

## 11. 의미가 비슷한 예시 선택하기

```python
from langchain_core.example_selectors import (
    SemanticSimilarityExampleSelector,
)

example_selector = SemanticSimilarityExampleSelector.from_examples(
    examples,
    OpenAIEmbeddings(),
    Chroma,
    k=1,
)
```

각 항목의 의미는 다음과 같다.

- `examples`: 검색 대상이 되는 예시 목록
- `OpenAIEmbeddings()`: 문장을 의미 벡터로 변환
- `Chroma`: 변환된 벡터를 저장하고 검색
- `k=1`: 가장 비슷한 예시 한 개 선택

작동 흐름은 다음과 같다.

```text
새로운 질문 입력
    ↓
질문을 Embedding으로 변환
    ↓
저장된 예시와 의미 비교
    ↓
가장 비슷한 예시 선택
```

## 12. 선택된 예시 확인하기

질문을 먼저 선언한 다음 예시를 검색해야 한다.

```python
question = "Google이 창립된 연도에 Bill Gates의 나이는 몇 살인가요?"

selected_examples = example_selector.select_examples(

for example in selected_examples:
```

```text

    ↓

```

`question`을 만들기 전에 사용하면 `NameError`가 발생한다.

## 13. 선택기를 Few-shot Prompt에 연결하기

고정 예시를 사용할 때는 `examples=examples`를 전달했다.

자동 선택 방식을 사용할 때는 대신 `example_selector=example_selector`를 전달한다.

```python
from langchain_core.prompts import (
    FewShotPromptTemplate,
    PromptTemplate,
)

example_prompt = PromptTemplate.from_template(
    "Question:\n{question}\nAnswer:\n{answer}"
)

prompt = FewShotPromptTemplate(
    example_selector=example_selector,
    example_prompt=example_prompt,
    suffix="Question:\n{question}\nAnswer:",
    input_variables=["question"],
)
```

최종 프롬프트는 다음과 같이 만든다.

```python
question = "새로운 질문"

final_prompt = prompt.format(
    question=question
)

print(final_prompt)
```

질문이 바뀌면 선택되는 예시도 자동으로 달라진다.

## 14. 예제 선택기와 모델 연결하기

```python
from langchain_openai import ChatOpenAI
from langchain_teddynote.messages import stream_response

llm = ChatOpenAI()

chain = prompt | llm

answer = chain.stream(
    {"question": "새로운 질문"}
)

stream_response(answer)
```

전체 실행 흐름은 다음과 같다.

```text
사용자 질문
    ↓
Embedding 변환
    ↓
의미가 가장 비슷한 예시 선택
    ↓
Few-shot Prompt 완성
    ↓
ChatOpenAI 답변 생성
    ↓
답변 실시간 출력
```

# 자주 발생한 오류 정리

## 15. `examples_prompt`와 `example_prompt`

잘못된 코드:

```python
FewShotPromptTemplate(
    examples_prompt=example_prompt
)
```

올바른 코드:

```python
FewShotPromptTemplate(
    example_prompt=example_prompt
)
```

생성자 인자 이름은 단수형인 `example_prompt`다.

---

## 16. `StrOutputParser` 인스턴스화

잘못된 코드:

```python
chain = prompt | llm | StrOutputParser
```

올바른 코드:

```python
chain = prompt | llm | StrOutputParser()
```

`StrOutputParser`는 클래스이므로 `()`를 붙여 객체를 만들어야 한다.

---

## 17. 스트리밍 결과 출력

잘못된 코드:

```python
stream_response
```

올바른 코드:

```python
stream_response(answer)
```

함수 이름만 작성하면 실행되지 않는다. `()`를 붙이고 출력할 `answer`를 전달해야 한다.

---

## 18. Chroma 대소문자

잘못된 코드:

```python
from langchain_chroma import chroma
```

올바른 코드:

```python
from langchain_chroma import Chroma
```

Python은 대소문자를 구분한다.

## 19. 패키지 설치 후에도 import 오류가 날 때

4. 저장된 과거 오류 출력과 현재 실행 오류를 구분한다.

올바른 코드:

```python
question = "새로운 질문"

selected_examples = example_selector.select_examples(
    {"question": question}
)
```

Python은 코드를 위에서 아래로 실행한다. 따라서 변수는 사용하기 전에 먼저 만들어야 한다.

## 21. 다른 노트북의 변수는 공유되지 않음

Chapter 5-6에서 만든 다음 변수들은 Chapter 5-7로 자동 전달되지 않는다.

```text
examples
example_prompt
llm
stream_response
```

각 노트북에서 필요한 변수와 import를 직접 준비해야 한다.

또한 커널을 재시작하면 현재 메모리에 있던 변수들이 모두 사라진다. 따라서 노트북은 가능하면 첫 셀부터 순서대로 실행하는 것이 안전하다.

# 최종 핵심 정리

- Few-shot Prompt는 예시를 통해 모델의 답변 방식과 형식을 유도한다.
- `PromptTemplate`은 한 개 예시의 출력 형식을 정의한다.
- `FewShotPromptTemplate`은 예시와 새 질문을 하나의 프롬프트로 합친다.
- 고정 예시는 `examples`로 전달한다.
- 자동 예시 선택은 `example_selector`로 연결한다.
- Embedding은 문장의 의미를 숫자 벡터로 변환한다.
- Chroma는 벡터를 저장하고 의미가 비슷한 내용을 검색한다.
- `k=1`은 가장 비슷한 예시 한 개를 선택한다는 뜻이다.
- LCEL의 `|`는 앞 단계의 결과를 다음 단계로 전달한다.
- `stream()`은 생성 중인 답변을 조각 단위로 반환한다.
- 변수와 import는 사용하는 노트북 안에서 먼저 준비해야 한다.
- 오류가 수정된 뒤에는 커널을 재시작하고 위 셀부터 순서대로 실행한다.
