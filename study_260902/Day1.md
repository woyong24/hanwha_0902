### 1. Condition: 조건문으로 데이터 걸러내기

핵심 개념

- `for`: 리스트의 값을 하나씩 반복해서 확인
- `strip()`: 문자열 앞뒤의 공백 제거
- `if not cleaned`: 값이 비어 있는지 확인
- `continue`: 현재 반복을 건너뛰고 다음 값으로 이동
- `append()`: 조건을 통과한 값을 리스트에 추가
- 빈 문자열이나 불필요한 데이터를 제거할 때 활용


### 2. List / Dict: 리스트와 딕셔너리로 데이터 구성

핵심 개념

- `list`: 여러 값을 순서대로 저장
- `dict`: `key: value` 형태로 데이터 저장
- `len()`: 리스트에 들어 있는 요소 개수 확인
- `response["count"]`: 딕셔너리에서 특정 key의 값 가져오기
- 리스트 데이터를 딕셔너리에 넣어 응답 형태로 구성 가능


### 3. Value Type: 변수 타입과 타입 힌트

핵심 개념

- `str`: 문자열
- `int`: 정수
- `float`: 실수
- `bool`: 참/거짓
- `변수명: 타입 = 값`: 변수에 타입 힌트 지정
- `type()`: 변수의 실제 자료형 확인
- 타입 힌트를 사용하면 코드에서 어떤 자료형을 사용하는지 쉽게 확인 가능
