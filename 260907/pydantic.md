### 1. 기본: 데이터 검증과 타입 변환

핵심 개념

- BaseModel: Pydantic 모델의 기본 클래스
- 타입 힌트로 데이터 타입 정의
- 문자열 `"25"`를 정수 `25`로 자동 변환
- 변환하거나 검증할 수 없는 데이터는 ValidationError 발생


### 2. 실전: 기본값, Optional, 중첩 모델

핵심 개념

- Field(): 값의 범위와 조건 설정
- `str | None = None`: 값이 없어도 되는 필드와 기본값 설정
- Nested Model: 모델 안에 다른 모델 사용
- dict 형태의 중첩 데이터를 모델 객체로 변환
- 중첩 데이터의 구조와 타입 검증


### 3. API 요청 → 검증 → 데이터 변환

핵심 개념

- API 요청 데이터의 형식 정의
- `Field()`로 문자열 길이와 숫자 범위 검증
- 요청 데이터를 Pydantic 모델로 검증
- 검증된 데이터를 함수에 전달하여 처리
- 잘못된 요청 데이터는 ValidationError 발생
