# Chapter 7-2 ~ 7-4 복습

이 범위는 **LLM에게 질문하기 → 같은 질문을 더 효율적으로 재사용하기 → 만든 체인을 저장하고 다시 쓰기** 흐름입니다.

## 7-2. 여러 LLM에 질문하기

LangChain은 OpenAI, Claude, Upstage처럼 서로 다른 AI 모델을 비슷한 방식으로 사용할 수 있게 도와주는 도구입니다.

- `ChatOpenAI(...)`처럼 **모델 객체**를 만든다.
- `stream("질문")`으로 답변이 완성되기를 기다리지 않고, 생성되는 부분부터 받는다.
- `stream_response(...)`는 받은 답변을 화면에 이어서 보여 준다.

모델마다 필요한 **패키지와 API 키가 다릅니다.** 쓰지 않을 모델의 패키지는 설치하지 않아도 됩니다.

```python
answer = gpt.stream("사랑이 뭔가요?")
stream_response(answer)
```

## 7-3. 체인과 캐시

**체인(chain)**은 “질문 양식 만들기 → AI 모델에 보내기”를 하나로 묶은 것입니다.

```python
chain = prompt | llm
response = chain.invoke({"country": "한국"})
```

- `PromptTemplate`의 `{country}`는 실행할 때 실제 값으로 바뀌는 빈칸이다.
- `invoke(...)`는 빈칸에 값을 넣어 체인을 실행하고 답변을 받는다.
- **캐시(cache)**는 같은 질문의 이전 답변을 저장해 두는 기능이다. 재실행 때 API 호출 비용과 대기 시간을 줄인다.

| 캐시 종류 | 어디에 저장? | 언제 사라지나? |
| --- | --- | --- |
| `InMemoryCache` | 현재 실행 중인 메모리 | 커널/프로그램 종료 시 |
| `SQLiteCache` | `llm_cache.db` 파일 | 파일을 지우기 전까지 |

캐시는 **질문과 설정이 같을 때** 가장 잘 재사용됩니다. 질문이나 모델 설정이 바뀌면 새로 AI를 호출할 수 있습니다.

## 7-4. 직렬화와 역직렬화

**직렬화**는 프로그램 안의 체인 객체를 딕셔너리·JSON·파일처럼 저장 가능한 형태로 바꾸는 일입니다.  
**역직렬화**는 저장한 데이터를 다시 실행 가능한 체인 객체로 되돌리는 일입니다.

```python
dumpd_chain = dumpd(chain)       # 체인 → 딕셔너리
pickle.dump(dumpd_chain, f)      # 딕셔너리 → 파일
chain_from_file = load(...)      # 파일 데이터 → 실행 가능한 체인
```

- `dumpd()`는 딕셔너리, `dumps()`는 JSON 문자열로 바꾼다.
- Pickle/JSON 파일로 저장하면 다음에 다시 만들어 쓰지 않아도 된다.
- API 키는 안전을 위해 저장 데이터에 넣지 않고, `load()`할 때 `secrets_map`으로 다시 연결한다.
- `allowed_objects="all"`은 **내가 직접 저장한 신뢰할 수 있는 파일**을 불러올 때만 사용한다.

## 한 줄 흐름

**API 키 준비 → 모델/프롬프트로 체인 만들기 → `invoke()`로 실행 → 필요하면 캐시 → 필요하면 파일로 저장 후 복원**
