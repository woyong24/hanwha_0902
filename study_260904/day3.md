### 1. Class: 데이터와 기능을 함께 관리하기

핵심 개념

- `class`: 관련된 데이터와 기능을 하나로 묶어 관리
- `__init__()`: 객체가 만들어질 때 처음 실행되는 함수
- `self`: 현재 만들어진 객체 자신을 의미
- `self.max_length`: 객체가 기억하고 있는 값
- `summarize()`: 클래스 안에 만든 함수인 메서드
- `TextService(max_length=20)`: 최대 글자 수를 20으로 설정한 객체 생성
- 같은 기능을 여러 번 사용하거나 설정값과 기능을 함께 관리할 때 활용


### 2. NumPy Operation: 배열 전체 계산하기

핵심 개념

- `np.array()`: NumPy 배열 생성
- `arr + 10`: 배열의 모든 값에 10을 더함
- `arr * 2`: 배열의 모든 값에 2를 곱함
- `sum()`: 배열 전체 값의 합계 계산
- `mean()`: 평균 계산
- `max()`: 최댓값 계산
- `axis=0`: 열을 기준으로 계산
- `axis=1`: 행을 기준으로 계산
- NumPy는 `for`문 없이 배열 전체를 한 번에 계산할 수 있음


### 3. NumPy Indexing: 필요한 데이터만 추출하기

핵심 개념

- `np.arange(9)`: 0부터 8까지 연속된 숫자 생성
- `reshape(3, 3)`: 데이터를 3행 3열 배열로 변환
- `matrix[1:, 1:]`: 원하는 행과 열 범위만 추출
- `matrix > 5`: 각 값이 5보다 큰지 `True / False`로 확인
- `mask`: 조건을 만족하는 위치를 표시하는 배열
- `matrix[mask]`: 조건이 `True`인 값만 추출
- 배열에서 특정 범위나 조건에 맞는 데이터만 가져올 때 활용


### 4. NumPy Reshape / Transpose: 배열 형태 바꾸기

핵심 개념

- `np.arange(12)`: 0부터 11까지 숫자 생성
- `reshape(3, 4)`: 1차원 배열을 3행 4열로 변환
- `.T`: 행과 열의 위치를 서로 바꾸는 전치
- `3x4 → 4x3`: 전치하면 행과 열의 개수가 서로 바뀜
- `reshape()`는 데이터 개수는 유지하고 배열 모양만 변경
- 데이터 구조를 분석하기 편한 형태로 바꿀 때 활용
