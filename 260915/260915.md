# LangChain Prompt 정리

## 1. LangSmith 프로젝트 설정

```python
from dotenv import load_dotenv
from langchain_teddynote import logging

load_dotenv()

logging.langsmith("0915-Prompt")
```

### 역할

- `load_dotenv()`
  - `.env` 파일에 저장된 API Key를 불러온다.

- `logging.langsmith("0915-Prompt")`
  - LangChain 실행 기록을 LangSmith에 저장하도록 설정한다.
  - `"0915-Prompt"`는 파일명이 아니라 LangSmith의 프로젝트 이름이다.

예를 들어 아래처럼 작성해도 실행에는 문제가 없다.

```python
logging.langsmith("Chapter_5_1.ipynb")
```

하지만 실제 `.ipynb` 파일을 연결하는 것은 아니다.

따라서 보통은 아래처럼 프로젝트 이름만 작성해도 된다.

```python
logging.langsmith("Chapter_5_1")
```


## 2. PromptTemplate이란?

먼저 일반 문자열로 프롬프트의 틀을 만든다.

```python
template = """
{country}의 수도는 어디인가요?
"""
```

여기서 `{country}`는 나중에 실제 값을 넣을 자리다.

이 문자열을 LangChain에서 사용할 수 있는 프롬프트 객체로 바꾼다.

```python
from langchain_core.prompts import PromptTemplate

prompt = PromptTemplate.from_template(template)
```

### 핵심

```python
PromptTemplate.from_template(template)
```

일반 문자열을 LangChain용 `PromptTemplate` 객체로 변환한다.

쉽게 보면:

```text
template
→ 일반 문자열

prompt
→ LangChain에서 사용할 수 있는 프롬프트 객체
```


## 3. 프롬프트에 실제 값 넣기

```python
prompt = prompt.format(country="대한민국")
```

`{country}` 자리에 `"대한민국"`을 넣는다.

변경 전:

```text
{country}의 수도는 어디인가요?
```

변경 후:

```text
대한민국의 수도는 어디인가요?
```

즉 `.format()`은 프롬프트의 변수 자리에 실제 값을 넣어 완성된 문장을 만드는 기능이다.

주의할 점은 `.format()`을 실행하면 완성된 문자열이 만들어진다는 것이다.

헷갈리지 않게 아래처럼 변수명을 나누어도 된다.

```python
prompt_template = PromptTemplate.from_template(template)

formatted_prompt = prompt_template.format(
    country="대한민국"
)
```


## 4. 마지막에 `prompt`를 또 쓰는 이유

```python
prompt = prompt.format(country="대한민국")
prompt
```

마지막의 `prompt`는 새로운 기능이 아니다.

Jupyter Notebook에서는 셀의 마지막 줄에 변수명을 적으면 그 변수의 값을 화면에 보여준다.

아래 코드와 비슷한 역할이다.

```python
print(prompt)
```

즉 마지막의 `prompt`는 결과 확인용이다.

없어도 코드 실행에는 문제가 없다.


## 5. 전체 흐름

```python
from langchain_core.prompts import PromptTemplate

# 1. 프롬프트 문장 틀 작성
template = """
{country}의 수도는 어디인가요?
"""

# 2. LangChain용 PromptTemplate으로 변환
prompt = PromptTemplate.from_template(template)

# 3. 변수에 실제 값 넣기
result = prompt.format(country="대한민국")

# 4. 결과 확인
result
```

결과:

```text
대한민국의 수도는 어디인가요?
```


## 6. Runnable 실행 방식

LangChain의 여러 객체는 Runnable 방식으로 실행할 수 있다.

### invoke()

입력 하나를 넣고 결과 하나를 받는다.

```python
result = chain.invoke("질문")
```

### stream()

결과를 한 번에 받지 않고 조금씩 받는다.

```python
for chunk in chain.stream("질문"):
    print(chunk)
```

### batch()

여러 입력을 한 번에 처리한다.

```python
results = chain.batch([
    "질문1",
    "질문2",
    "질문3"
])
```

쉽게 기억하면:

```text
invoke = 하나 실행
stream = 결과를 조금씩 받기
batch = 여러 개 실행
```


## 핵심 요약

```text
template

PromptTemplate.from_template()
= 일반 문자열을 LangChain 프롬프트 객체로 변환

.format()
= {변수} 자리에 실제 값을 넣음

prompt
= 사용자가 정한 변수명

Notebook 마지막 줄의 prompt
= 현재 값 확인용

logging.langsmith()
= LangSmith에서 실행 기록을 모을 프로젝트 이름 설정

invoke()
= 하나 실행

stream()
= 결과를 조금씩 받음

batch()
= 여러 입력을 한 번에 실행
```
